# ADR-0006: クラスタリング変更は実リレーデータでの検証を完了条件とする

- ステータス: 採用
- 日付: 2026-06-10

## コンテキスト

クラスタリングの品質は合成データやユニットテストだけでは判定できない。実際、ヒューリスティックな旧実装はテストを全て通過しながら、実データで巨大クラスタ崩壊を起こしていた。逆に「フォローエッジは有害」「重み比は鈍感」という設計上の重要な発見は、いずれも実データの計測からしか得られなかった。

## 決定

クラスタリング・グラフ構築の変更は`scripts/eval-clustering.ts`での検証を完了条件とする。

- `bun scripts/eval-clustering.ts fetch` が公開リレーから実イベントを取得し、JSONにキャッシュする（再現性のため）
- `bun scripts/eval-clustering.ts run [cache.json]` が新旧手法を同一データで比較し、Q・カバレッジ・バランス・クラスタサイズ・**イベント順反転での安定性**を報告する
- 重み等のパラメータ調整は単一スナップショットで最適化せず、別時間帯の第2データセットで再現確認する（過学習防止）

## 結果

- 「論文があるアルゴリズム」かつ「実データで良い分析」という二重の根拠が変更ごとに残る
- 検証結果の要約は`docs/clustering.md`に転記し、コード内コメントは測定値を引用する
- キャッシュは`scripts/.cache/`（gitignore済み）。リレーの状態に依存するため、数値の完全再現には同一キャッシュが必要
