# ADR-0004: 多面クラスタリングと品質スコアによる自動選択

- ステータス: 採用
- 日付: 2026-06-10

## コンテキスト

単一のクラスタリング手法はデータの状態に依存する: ハッシュタグが少なければトピック面は空振りし（実測カバレッジ8%）、インタラクションが疎ならコミュニティ面のカバレッジが落ちる。ユーザの要求は「多角的なクラスタリング」と「一番いいクラスタリングの動的適用」である。

## 決定

4つの面（facet）を提供し、共通の品質スコアで採点して最良の面を自動適用する「Auto」モードを既定にする。

- 面: Community（Louvain）/ Topic（ハッシュタグ共起+Louvain）/ Language / Engagement（RFM 5分位）
- 品質スコア: `0.5·max(0,Q) + 0.3·coverage + 0.2·balance`（k<2なら×0.2）
  - Q: 対インタラクショングラフのモジュラリティ（Newman & Girvan 2004）。全面を同じ物差しで「実際の社会構造との整合」で測る
  - coverage: クラスタに割り当てられたノート著者の割合
  - balance: クラスタサイズの正規化エントロピー（1巨大クラスタ縮退の罰則)
- UIは選択された面と3指標を常時表示し、ユーザは手動で面を切り替えられる

## 結果

- 実データでAutoはCommunity面（score 0.585）を正しく選択し、ハッシュタグ過疎のトピック面（0.198）を回避した
- Autoモードは毎回4面すべてを計算する。現データ規模（数百ユーザ）ではコストは無視できる
- 合成スコアの重み（0.5/0.3/0.2）は製品判断であり、指標自体（モジュラリティ・カバレッジ・エントロピー）は標準。重みの変更はUIの3指標表示で透明に検証できる
